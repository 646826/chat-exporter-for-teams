# Chat Exporter for Microsoft Teams 0.2.2

## Fixes

- Ordinary website previews and generic `role=document` containers no longer turn links into failed file downloads. Explicit file cards, media and download links remain attachments.
- SharePoint Office viewer URLs with valid document GUIDs try a site-scoped download endpoint first. Original URLs remain available as fallbacks. Existing signed download URLs are not rewritten.
- Transient network/HTTP failures use bounded retries. All alternatives for one attachment share one deadline, rather than restarting the deadline for every URL.
- Cancel and timeouts remain responsive even when a page fetch wrapper ignores AbortSignal or a stream cancellation hook never settles. Late responses are discarded.
- Ephemeral media capture has bounded concurrency and size checks. Zero-byte blob/data attachments and explicitly named empty HTTP downloads are preserved.
- Network HTML viewer/sign-in responses are rejected before their bodies are buffered; local HTML blobs are preserved as files.
- Meaningful filenames and actual request history survive prefetch, download failure and archive-budget rejection.
- The completion panel explicitly shows downloaded, failed and skipped counts, including an incomplete-archive warning in all eight supported UI languages.
- Diagnostics add error codes and attempt history. Existing Markdown, HTML, JSON and CSV contents remain; JSON format is still `chat-exporter-for-teams/v1`.
- Browser verification runs with a fresh profile on macOS and Linux. New tests cover a real local HTTP server through to ZIP assembly, binary integrity, retry, empty files, missing files and stalled responses.
- Explicit Chrome Web Store publication fails visibly when Store authorization is absent; a successful build is not publication.

## Исправления

Исправлена классификация ссылок и вложений, добавлены корректные варианты скачивания документов SharePoint, общий таймаут на файл и ограниченные повторные запросы. Устранены зависания отмены, потеря пустых файлов, ошибки имён и неполная история загрузок. Архив с недостающими файлами теперь явно обозначается в интерфейсе.

## Scope and delivery

No new permissions, runtime dependencies or backend. The optional privileged cross-origin transport was not implemented after its source-creation action was rejected. Requests still use the current signed-in page context. CORS, missing access, expired sharing links, tenant policy and deleted files may prevent download. Website links are preserved, not claimed to be offline copies of the linked application.

The reported real conversation has not been re-exported in this verification session. Synthetic fixtures and local HTTP tests do not prove that all files in a particular Microsoft 365 tenant are accessible.

Store upload, review submission and public availability are separate from this source version. Consult current workflow results; no Store delivery is implied by these release notes.
