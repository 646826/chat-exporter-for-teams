# Chat Exporter for Microsoft Teams 0.2.1

## What's new
- Cancel large ZIP exports during attachment checksum processing, instead of waiting for an entire file.
- Checksum processing yields periodically to browser tasks and reads bounded slices.
- Cancellation keeps its correct status instead of being reported as ZIP_BUILD_FAILED.
- Work cancelled before archive creation does not start rendering or reading files.
- Existing Markdown, HTML, JSON, CSV and attachment contents are retained.

## Что нового
- Отмена экспорта обрабатывается во время вычисления контрольных сумм больших вложений.
- Обработка периодически отдаёт управление браузеру и читает файлы небольшими порциями.
- Отмена больше не отображается как ошибка создания ZIP.
- Заранее отменённая операция не начинает формирование архива.
- Сохранены прежние форматы экспорта и содержимое вложений.

## Release scope and delivery
Includes merged PR #6 and all 0.2.0 changes. The separate local message-discovery optimization is NOT included: its repository write was blocked and was not retried through another mechanism.
No new permissions, dependencies or archive-format changes. Cancellation is cooperative; this is not a global memory cap or a measured throughput increase.
Manifest, npm metadata and bundle identity are 0.2.1. Existing full verification and release automation are unchanged. Automatic delivery uses its existing upload-only default for this version; publication requires the configured Store credentials and an explicit manual DEFAULT_PUBLISH run. Missing credentials must be reported as no delivery, not a successful publication.
