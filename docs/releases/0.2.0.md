# Chat Exporter for Microsoft Teams 0.2.0

## What's new
- Every new export ZIP includes `chat.md`: a Markdown transcript with authors, timestamps, literal message text, reactions and links.
- Downloaded attachments are linked locally; unavailable attachments retain their status and reason. Existing HTML, JSON and CSV exports remain included.
- Oversized network attachments are stopped while reading instead of being fully buffered before rejection. Cached attachments also respect the single-file archive limit.
- Reduced repeated timestamp parsing when sorting long conversations.
- Expanded archive, attachment and browser regression checks.

## Что нового
- В каждый новый ZIP добавлен `chat.md` с текстом переписки, авторами, временем сообщений, реакциями и ссылками.
- Для скачанных вложений используются локальные ссылки; для недоступных сохраняются статус и причина. HTML, JSON и CSV остаются в архиве.
- Слишком большие сетевые вложения отклоняются во время чтения, без необходимости сначала полностью загрузить файл.
- Уменьшено число повторных вычислений при сортировке длинных переписок.
- Расширены проверки содержимого архивов, вложений и работы в браузере.

## Release scope
Includes merged PRs #1, #2 and #4. The Markdown file preserves captured plain text; use HTML for rich formatting. Exact ZIP allowlists must allow the additional `chat.md` entry. JSON schema remains `chat-exporter-for-teams/v1`.
No new permissions or runtime dependencies. The change does not bypass Microsoft 365 access controls, recover inaccessible data or impose a total-process memory bound.
Store submission uses normal review (`skipReview=false`) when this repository has store credentials. Submission is distinct from publication; consult store-status evidence.
