# 0.2.2 candidate: review gate BLOCKED

Status: not merged, not published, not ready for installation. Issue #8 remains open.

The initial bounded repair passed GitHub CI run 36576395825 at commit 75ba204. Independent read-only review then found five P2 defects. Eleven targeted regression cases reproduce them: 0 passed, 11 failed. The proposed corrective source edit was rejected by the execution tool; a subsequent diff check confirmed it did not apply. These tests deliberately remain failing to prevent a misleading release gate.

## Confirmed defects

1. Awaiting response-body cancellation can hang forever, defeating timeout and Cancel. Reproduced for transient retries, declared oversized responses and streams that exceed the limit while reading.
2. The new prefetch path rejects valid empty blob/data attachments that the previous version could include as zero-byte files.
3. Invalid or revoked blob/data URLs are retried as network failures even though another request cannot restore them.
4. Prefetch drops actual request-attempt history on success, failure and cache-budget rejection. The new CSV diagnostics can therefore omit requests that occurred.
5. Generic Link/Shared filename handling can replace a meaningful filename with an opaque URL basename such as download.

Reproduction: `node --test tests/unit/attachment-review-regressions.test.mjs`.

## Required next gate

Do not remove, skip or relabel these regressions to obtain green CI. Only after their assertions and the complete suite pass can the bounded candidate be considered for merge.
